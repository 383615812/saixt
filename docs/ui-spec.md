# 前端 UI 专业美化提升 · 规格说明（Spec）

> 项目：saixt 云南春招智能学习平台
> 版本：v1.0（2026-09-03）
> 状态：待评审

---

## 1. 目标与原则

### 1.1 目标

将前端 UI 提升至国内外大厂一流标准：**清晰醒目、美观大方、使用流畅**，减少"AI 生成感"，建立专业、可信、有温度的品牌形象。

### 1.2 核心原则

| 原则 | 说明 |
|---|---|
| **品牌一致** | 全站统一使用沉稳靛蓝 `#4f5ff0` 主色体系，禁用薰衣草紫 `#8b5cf6`（除语义场景） |
| **浅色系** | 保持浅色底 + 白卡片 + 靛蓝强调的配色基调 |
| **真实数据** | 所有展示数据为真实数据，无 mock |
| **响应式** | 移动端 / 平板 / 电脑三端均达到良好显示效果 |
| **克制留白** | 页面不留过多空白，信息密度合理 |
| **可读性** | 深色背景与文字对比度 ≥ 4.5:1（WCAG AA） |
| **减少 AI 感** | 避免千篇一律的渐变卡片堆砌，追求精致细节与专业排版 |

## 2. 设计系统（Design Tokens）

### 2.1 配色规范

现有 `main.css` 已定义基础变量，本次**补齐并统一**以下 token：

| Token | 值 | 用途 |
|---|---|---|
| `--accent` | `#4f5ff0` | 主色（品牌靛蓝） |
| `--accent-deep` | `#3d4de0` | 主色深色（hover/按下） |
| `--accent-2` | `#6b58e8` | 辅助紫（仅特定语义） |
| `--gradient-accent` | `linear-gradient(135deg, #4f5ff0, #2563eb)` | 主渐变（按钮/进度/强调） |
| `--green` | `#0da678` | 成功/正确 |
| `--amber` | `#d97706` | 警告/积分 |
| `--red` | `#e11d48` | 错误/危险 |
| `--vip-gold` | `#f59e0b` | VIP 金色徽章（品牌识别） |

**规则**：
- 业务页面禁止硬编码色值，一律使用 CSS 变量
- 状态色（成功/警告/错误）统一使用 `--green/--amber/--red`
- 渐变统一使用 `--gradient-accent`，禁止散落 `#2563eb` 等硬编码

### 2.2 字体规范

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | `1.55rem` | 800 | `.page-head h2` |
| 卡片标题 | `1.1rem` | 700 | 卡片 h3 |
| 正文 | `0.92rem` | 400 | 正文/按钮/导航 |
| 辅助 | `0.84rem` | 400 | 说明文字 |
| 标签 | `0.74rem` | 500 | tag/元信息 |
| 统计数字 | `1.6-2rem` | 700 | 关键指标 |

**规则**：所有字号 ≥ 0.7rem；数字使用 `tabular-nums` 对齐。

### 2.3 间距 / 圆角 / 阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius` | `16px` | 卡片 |
| `--radius-sm` | `10px` | 按钮/输入框 |
| `--radius-lg` | `22px` | 大容器/弹层 |
| `--radius-full` | `999px` | 标签/头像 |
| 卡片内边距 | `22px`（移动端 16-18px） | 统一 |
| 卡片阴影 | `--shadow` | 统一 |

## 3. 组件规范

### 3.1 导航栏（AppTopbar / AppDrawer）

**现状**：顶栏已具备毛玻璃效果，但用户反馈"讨厌丑陋的桌面导航栏设计"，需重构优化。

**目标**：
- 顶栏：更精致的品牌区（Logo + 名称 + 定位）、更清晰的导航层级、更优雅的"更多"面板
- 激活态：当前路由导航项使用主色 + 渐变下划线/胶囊高亮
- 移动端抽屉：分组更清晰、间距更舒适、图标统一
- 顶栏与页面内容衔接自然，滚动时阴影过渡平滑

### 3.2 卡片系统

**目标**：统一卡片视觉层级
- 普通卡片：白底 + 1px 浅边框 + 圆角 + 轻阴影
- 强调卡片（统计/重点）：顶部主色渐变细条或浅色渐变底
- 可交互卡片（院校/题目）：hover 时轻微上浮 + 边框主色化

### 3.3 按钮

**目标**：统一按钮体系
- 主按钮：`--gradient-accent` 渐变底 + 白字 + 柔和投影
- 次按钮（ghost）：白底 + 主色边框/文字
- 危险按钮：红色系
- 统一 hover/active/disabled 状态

### 3.4 标签 / 状态色

**目标**：统一业务标签
- 全局 `.tag` 体系（blue/purple/green/amber/red）
- 公办/民办、冲/稳/保、正确/错误等状态统一使用语义色
- 消除 TierBlock、PaperPractice 等组件内的局部硬编码标签色

### 3.5 表单

**目标**：统一输入控件
- 统一 input/select/textarea 的边框、圆角、focus 态（主色边框 + 柔和光晕）
- 标签与输入框间距统一
- 错误提示统一样式

### 3.6 图表（KnowledgeGraph / DataScreen / RadarChart）

**目标**：图表与主题统一
- 图表容器统一边框/圆角
- 提示框（tooltip）统一为浅色底 + 主色边框（大屏页除外）
- 图表配色统一使用主题变量，消除硬编码灰色

## 4. 页面级规范

### 4.1 首页（Home.vue）
- Hero 区：强化品牌叙事，主标题 + 副标题 + 双 CTA，背景渐变与装饰元素精致化
- 考试构成 / 倒计时模块：信息卡片化，倒计时数字醒目
- 推荐模块：与全站卡片风格统一

### 4.2 院校库（Schools.vue）
- 筛选栏：搜索框 + 筛选 chips 统一间距与样式
- 院校卡片：Logo 区 + 名称 + 关键指标（性质/地州/学费）+ hover 上浮
- 空状态 / 加载骨架屏统一

### 4.3 院校详情（SchoolDetail.vue）
- 概况区：院校信息卡片化，关键数据（计划数/学费区间）醒目展示
- 招生计划表格：表头吸顶、行 hover、学费格式化清晰

### 4.4 志愿推荐（Recommend.vue）
- 输入区：表单卡片化，标签 + 输入框 + 提示文案层次清晰
- 结果区：冲/稳/保分层卡片（TierBlock）视觉强化，层级色统一
- 生成中状态：进度反馈精致化

### 4.5 学习周报（WeeklyReport.vue）
- 统计面板：核心指标卡片化（刷题数/正确率/打卡/模拟考）
- 环比对比：升降标识统一（持平灰色、上升绿色、下降红色）
- AI 总结区：文本卡片化，可读性优先

### 4.6 错题本（WrongBook.vue）
- 题目卡片：题干/选项/解析层次清晰
- 操作区：重练/解析/AI 讲解/已掌握按钮组统一间距与层级
- 筛选栏：科目/章节 chips 统一

### 4.7 任务中心（Tasks.vue）
- 进度环 + 进度条统一主题渐变
- 任务项：图标 + 名称 + 进度 + 状态清晰
- 空状态：引导性文案 + 行动按钮

### 4.8 学习计划（Plan.vue）
- 统计卡片：四宫格统一
- 薄弱知识点：列表化 + 掌握度色条
- AI 计划/分析：文本卡片化

### 4.9 其他页面（Practice / AiPractice / PaperPractice / Login / Ranking / Achievements / ReviewPlan / Remind / Favorites / Dashboard / Vip / Points / Invite / BlindBox / Admin）
- 统一 `.page-head`、`.card`、`.chip`、`.btn` 体系
- 消除局部硬编码颜色
- 空状态 / 加载态 / 错误态统一

---

## 5. 响应式规范

| 断点 | 适配要点 |
|---|---|
| ≤900px | 主导航隐藏 → 汉堡菜单 + 抽屉 |
| ≤768px | 卡片网格降为 2 列 / 单列 |
| ≤600px | 顶栏高度 56px、卡片内边距 16px |
| ≤480px | 圆角 14px、标签字号 0.7rem |

**规则**：
- 所有多列网格在移动端折叠为单列
- 表格在窄屏横向滚动（`.table-wrap`）
- 图表容器自适应高度

---

## 6. 可访问性

- 正文/背景对比度 ≥ 4.5:1
- 所有可交互元素有 hover/focus 态
- 表单控件有清晰 label
- 颜色不作为唯一信息传达手段（配合图标/文字）

---

## 7. 验收标准

1. 全站无硬编码业务色（除 VIP 金色等品牌识别色）
2. 所有页面统一使用 `.page-head / .card / .chip / .btn / .tag` 体系
3. 桌面 / 平板 / 移动三端截图对比无明显布局错乱
4. 浏览器 console 无报错，网络无 4xx/5xx
5. 真实数据展示完整，无 mock
6. 构建通过，CI 冒烟通过
