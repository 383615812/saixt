> 项目：saixt 云南春招智能学习平台

> 状态：✅ 已实施完成 · 三端验证通过
> 关联文档：[ui-spec.md](./ui-spec.md)（全站设计系统）、[ui-mobile-plan.md](./ui-mobile-plan.md)

## 1. 背景与目标

### 1.1 背景

全站桌面端 UI 已完成第一轮专业美化（P0-P4），但移动端（≤768px，尤其 ≤480px）仍存在一批影响体验的硬伤：部分触控目标低于 40px 最小规范、弹窗在窄屏仍是固定宽度而非全屏、若干页面缺少 480px/400px 细分断点、多处辅助字号处于 0.7rem 可读性临界值。用户在手机/平板上访问时，这些细节直接决定"是否好用"。

### 1.2 目标

在不改变桌面端既有视觉的前提下，把移动端体验补齐到与桌面端同等的专业水准：

| 维度 | 目标 |
|---|---|
| 触控 | 所有可点击元素最小触控高度 ≥ 40px（主操作 ≥ 44px） |
| 弹窗 | 移动端弹窗/抽屉/搜索面板全屏或近全屏，关闭按钮触控友好 |
| 断点 | 全站统一 768 / 480 / 400 三级断点体系，页面级按需补充 |
| 可读性 | 移动端辅助字号不低于 0.72rem，正文不低于 0.85rem |
| 布局 | 无横向滚动、无内容挤压、多列折叠为单列、表格横向滚动 |
| 一致性 | 移动端与桌面端共用同一套设计 Token 与组件体系 |

## 2. 移动端设计规范

### 2.1 触控目标

| 元素 | 最小尺寸 | 说明 |
|---|---|---|
| 主按钮 `.btn` | 44px 高 | 已达标，保持 |
| 次按钮 `.btn-sm` | **40px 高**（现 34px） | 全局统一提升 |
| 开关 `.switch` | **36px 高**（现 32px） | Remind 页 |
| 弹窗关闭按钮 | **≥ 36×36px**（现 4px 8px padding） | 全站弹窗 |
| 列表行 / 选项 | ≥ 44px 高 | 题目选项已达标 |
| 抽屉菜单项 | ≥ 44px 高 | AppDrawer |

### 2.2 字号基线（移动端）

| 层级 | 最小字号 | 说明 |
|---|---|---|
| 页面标题 | 1.3rem | 已达标 |
| 卡片标题 | 1.05rem | 已达标 |
| 正文 | 0.92rem | 已达标 |
| 辅助文字 | **0.75rem** | 现多处 0.7-0.72rem，统一提升 |
| 标签 `.tag` | **0.72rem** | 现 0.7rem，提升 2px 保可读 |
| 统计数字 | 1.4rem | 已达标 |

### 2.3 断点体系

全站统一三级主断点，组件/页面按需补充 600px：

| 断点 | 适配要点 |
|---|---|
| ≤768px | 卡片内边距 18px、容器 16px、网格降列 |
| ≤600px | 页面级细节调整（页头字号、按钮全宽等） |
| ≤480px | 卡片内边距 14px、容器 12px、圆角缩小 |
| ≤400px | 极窄屏兜底（统计数字、选项字母缩小） |

### 2.4 弹窗 / 抽屉规范

| 场景 | 移动端规则 |
|---|---|
| 内容弹窗（周报详情/海报） | `width: calc(100vw - 24px)`，`max-width: 520px`，底部圆角 18px |
| 搜索面板 AppSearch | 近全屏：`width: calc(100vw - 16px)`，顶部圆角 |
| 抽屉 AppDrawer | 宽度 ≥ 78vw，独立滚动，菜单项 44px 高 |
| 关闭按钮 | 统一 36×36px 圆形，hover/active 反馈 |

## 3. 页面级适配清单

### 3.1 全局（main.css）

- `.btn-sm` 最小高度 34px → 40px（480px 下 32px → 40px）
- `.tag` 字号 0.7rem → 0.72rem（768px 断点内）
- 补充 `@media (max-width: 400px)` 极窄屏兜底

### 3.2 应用壳（App.vue / AppTopbar / AppDrawer / AppSearch）

- 底部 TabBar 激活态在移动端保持主色渐变指示，图标与文字间距合理
- 页脚在 ≤480px 单列布局，字号 ≥ 0.8rem
- 抽屉宽度 260px → 78vw，菜单项触控高度 44px
- 搜索面板移动端近全屏

### 3.3 弹窗类页面

| 文件 | 问题 | 修复 |
|---|---|---|
| WeeklyReport.vue | 详情弹窗 max-width 620px | 移动端 `calc(100vw - 24px)` |
| Achievements.vue | 海报弹窗 max-width 520px | 移动端近全屏 |
| AppSearch.vue | 搜索面板 max-width 600px | 移动端近全屏 |
| 各弹窗关闭按钮 | padding 4px 8px | 统一 36×36px 圆形按钮 |

### 3.4 触控目标

| 文件 | 问题 | 修复 |
|---|---|---|
| Remind.vue | `.switch` 高 32px | 高 36px，滑块同步 |
| Schools.vue | `.btn-sm` 高 38px | 40px |

### 3.5 断点补齐

| 文件 | 现状 | 修复 |
|---|---|---|
| Tasks.vue | 仅 600/400px | 补 480px |
| Recommend.vue | 仅 600/700px | 补 480px |
| Favorites.vue | 仅 600px | 补 480/400px |
| SchoolDetail.vue | 600/480/768px | 补 400px |
| KnowledgeGraph.vue | 768/480px | 补 600px |

### 3.6 辅助字号提升（0.7-0.72rem → 0.75rem）

涉及页面：Tasks、WeeklyReport、ReviewPlan、Achievements、Ranking、Remind、Favorites、Schools、Dashboard 等中的状态标签、日期、图例、统计标签。

## 4. 验收标准

1. 全站可点击元素最小触控高度 ≥ 40px（grep 巡检 + 截图抽查）
2. 移动端（375×667 / 390×844）截图无横向滚动、无内容挤压
3. 弹窗/抽屉/搜索面板在移动端近全屏，关闭按钮触控友好
4. 全站辅助字号 ≥ 0.72rem，无 0.7rem 临界值
5. 桌面端视觉无回归（与优化前截图对比）
6. 构建通过，`smoke:gate` + `test:web` + e2e 冒烟通过
